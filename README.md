# Dexterous Hand Project Study

灵巧手项目学习与开发仓库 —— 跟随立芯恒方 EC-EB01 五指灵巧手课程（五阶段 21 课）边学边做，以开源方式沉淀完整开发目录。

## 目录结构（规划）

| 目录 | 用途 |
| --- | --- |
| `docs/` | 需求清单、系统架构、接口定义、评审记录 |
| `firmware/` | 主控与电机控制固件（FOC、STM32、CAN、Ethernet/LWIP） |
| `ros2/` | 上位机 ROS2 节点、仿真与调试工具 |
| `hardware/` | 机械结构、台架资料、BOM |
| `tools/` | 脚本、工具链、自动化 |

> 说明：各目录随学习阶段逐步填充。个人笔记与求职材料为私有内容，不入本仓库。

## 学习主线

1. **阶段一（16 周）**：Git/GitHub → C++ 最小增量 → Linux/WSL2 → ROS2 → 电机控制理论（跟立芯课程），台架实战并行
2. **阶段二**：灵巧手项目攻坚（成熟台架 5 步法：选型 → 拆解 → 跑通 → 移植 → 自研）
3. **阶段三**：求职冲刺（嵌入式 / 电机驱动 / 机器人软件方向）
